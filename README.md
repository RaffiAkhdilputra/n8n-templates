### Installation Steps

1. Clone this repository:  
   ```bash
   git clone https://github.com/RaffiAkhdilputra/n8n-templates.git
   cd n8n-templates
2. Import the desired workflow file into your n8n instance:
   -  Open n8n Dashboard
   -  Go to Workflows → Import from File
   -  Select any .json file from this repository
   -  Click Import
3. Update the required credentials inside the workflow:
Depending on the project, you may need to configure:
    - Credentials
    - Webhook URL
    - AI API Key
4. Channel ID, Guild ID, Document ID, etc.
5. Save and activate the workflow to start using it.

📦 Requirements
